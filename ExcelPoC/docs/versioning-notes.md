# Versioning Notes

The included uploaded documentation jar is `26.4`, while the Maven dependency is pinned to `26.3` because Aspose's public Java Maven repository has historically lagged the newest documentation drop.

If `26.4` becomes available in the repository you can update:
```xml
<aspose.cells.version>26.4</aspose.cells.version>
```

If your organization distributes the jar internally instead of resolving from Aspose's repository, adapt the build accordingly.
