# Javadoc Notes

This project is designed around the Aspose.Cells Java object model:
- `Workbook` to open and save workbooks
- `Worksheet` to enumerate sheet scope
- `Cells` and `Cell` to inspect and update individual cell content

The included reference jar is the uploaded `aspose-cells-26.4-javadoc.jar` used as the local documentation source for this PoC.
